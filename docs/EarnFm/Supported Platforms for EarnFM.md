# Supported Platforms for EarnFM

EarnFM offers a versatile range of platform support to cater to both mobile and desktop users. Here's a list of platforms compatible with EarnFM:

## EarnFM Compatibility

- **Windows:** Full support for users with Windows operating systems.
- **macOS:** Compatible with macOS for Apple desktop users.
- **Android:** Available for Android mobile devices.
- **iOS:** Supports iOS devices, adhering to Apple's app guidelines.
- **Linux:** Linux users can also benefit from EarnFM.
- **Docker:** Docker support for advanced users and scalability.

### Assistance with Compatibility Issues

- **Ticket Support:** If you encounter any compatibility issues, please submit a support ticket for assistance.

EarnFM's wide platform support ensures accessibility for a diverse range of users.
