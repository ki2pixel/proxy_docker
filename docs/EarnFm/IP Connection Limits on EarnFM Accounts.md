# IP Connection Limits on EarnFM Accounts

EarnFM supports scaling across many devices, with different limits for residential and datacenter use.

## Residential IPs (EarnFM app)

- Standard accounts can connect up to **50 residential IPs** via the EarnFM app.
- If you can provide **20 or more** residential IPs and need Fleetshare access, apply here: [Supplier portal / Fleetshare](#).

## Datacenter IPs

- There is no fixed upper limit for authorized datacenter connections on a single account.
- All connections must be legitimate and comply with our terms.

Always use **one EarnFM account** for all of your devices.

<https://help.earn.fm/portal/en/kb/articles/how-many-ips-can-i-connect-on-my-account>
